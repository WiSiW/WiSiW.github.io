【LangGraph】基于 LangGraph 构建完整的长期记忆系统

一、整体架构设计

整个系统可以划分为五个核心模块。

模块一：对话管理模块

负责接收用户输入、维护会话状态。

主要功能：

  • 创建和管理 Conversation。
  • 通过 thread_id 管理会话。
  • 保存完整历史消息。
  • 管理最近消息窗口。
  • 控制上下文 Token 数量。
    推荐使用 LangGraph Checkpointer。

模块二：记忆提取模块

负责从历史对话中识别具有长期价值的信息。

主要功能：

  • 实体提取。
  • 用户偏好提取。
  • 项目信息提取。
  • 事实和关系抽取。
  • 对话摘要生成。
  • 记忆重要性评分。
    推荐使用 LLM Structured Output。

模块三：记忆存储模块

负责对不同类型的记忆进行分类存储。
存储介质 | 存储内容
—|—
PostgreSQL / MySQL | 用户画像、实体、结构化事实、记忆元数据
Redis | 热门记忆缓存、会话状态缓存
Chroma / Milvus | 向量化历史记忆
Neo4j | 实体及其关系
PostgreSQL Checkpointer | 会话状态及消息历史

模块五：记忆管理模块

  • 记忆新增。
  • 记忆更新。
  • 记忆去重。
  • 记忆冲突处理。
  • 记忆过期。
  • 记忆删除。
  • 记忆权限控制。
