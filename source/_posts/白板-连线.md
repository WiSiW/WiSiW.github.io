# 2.两点之间连线

点虽然是圆形，但如果放大，就会变成圆形，因此我们将圆点连线的出发点或者结束点分为四个（上、下、左、右）。换句话说其实还是两点之间的连线，我们将线的出发点和结束点设定为圆点的中心。

首先，我们设定两个略大于或者略小于线宽的点，进行两点之间的连线。

## 2-1.获取两点的位置
出发点为```from```，结束点为```to```

点的数据结构为
```json
{
  "top": 0,
  "left": 0,
  "width": 0,
  "height": 0,
}
```

## 2-2.计算连线的位置、宽高
计算两点的相对位置，获得```[最顶部、最右侧、最底部、最左侧]```

连线并不设定宽高，根据设定上下左右的距离来实现
top：最顶部元素的```top - ( height / 2 )```
right：最右侧元素的```left + ( width / 2 )```
bottom：最底部的元素的```top + ( height / 2 )```
left：最左侧元素的```left + ( width / 2 )```
