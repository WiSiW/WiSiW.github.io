## 系统核心：数据语义

例如：

> 今年华东地区销售量增长如何？

人理解的是：

```
今年
+
华东地区
+
销售
+
增长
```

但数据库可能是：

```
dw_order
    order_amount
    order_time
    province_code
    customer_id
```

模型必须知道：

```
销售额
    ↓
SUM(order_amount)

今年
    ↓
2026-01-01 ~ 2026-12-31

华东
    ↓
江苏、浙江、上海、安徽、福建、江西、山东……

增长
    ↓
同比 / 环比？
```

因此需要建立：

```
Semantic Layer（语义层）
```

这是整个系统的核心资产。
