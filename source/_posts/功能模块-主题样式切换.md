# 不同主题切换
主要使用```css```的定义变量功能

```html
<style>
  div {
    width: 100%;
    height： 100vh;
    display: flex;
    align-items: center;s
  }
  .dark {
    --dark-bg-color: #000000;
    --dark-text-color: #ffffff;
  }
  .dark div{
    background-color: var(--dark-bg-color);
  }
  .dark span{
    color: var(--dark-text-color);
  }
</style>
<body>
  <div>
    <span>hello world!</span>
  </div>
</body>
```
